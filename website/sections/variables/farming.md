!!! note "Needs the Time Tracking plugin"
    `{farming}` reads RuneLite's **Time Tracking** plugin, so keep it on. A patch counts once Time Tracking has seen it.

`{farming}` alone lists every kind of patch growing or finished in the last 24 hours.

!!! note "Keep a `{farming}` label showing while patches grow"
    The 24 hours count from when a patch finished, which is noted only while a `{farming}` label is drawn as it grows.
    Otherwise, once done it's left off plain `{farming}`, though `{farming Herbs}` still shows Ready.
